# DIRECTIVE — redhot-base

The Redhot Suite is a keyboard-first desktop productivity ecosystem for
Unix/BSD and minimalist Linux users who need operational fluidity without
bloat. It wins through deterministic integration via flat files, low
cognitive load, and an autonomous offline graphical installer written in D.
It explicitly refuses relational databases, telemetry, and generic desktop
daemons. Success is measured by a new user installing the suite, browsing,
editing documents, and running safe backups in under five minutes without
touching the mouse.
